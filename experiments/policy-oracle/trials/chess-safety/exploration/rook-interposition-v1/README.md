# One rook reply changes the result

White has king a6 and queen g4. Black has king a8 and one rook. White plays Qg8+ in both positions. With the black rook on c5, the only legal reply is ...Rc8. With it on h5, the same queen move delivers mate. For each position the oracle submits the same board under all three status claims.
