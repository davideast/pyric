# Design and media sources

UI adapted from the user-supplied [Social dashboards mobile Figma design](https://www.figma.com/design/GiixTHg4blUrT4rqihJPKF/social-dashboards-mobile-figma).

Inspected nodes: `3598:6621`, `3598:8844`, `3598:8824`, `3598:8611`, `3598:8463`, `3598:8204`, `3598:8176`, `3598:7971`, `3598:7805`, `3598:7774`, `3598:7564`, `3598:7364`, `3598:6726`, `1:332`.

- Feed cards, rounded avatars, blue navigation: `3598:6726`.
- Charcoal chat header, white conversation sheet, voice messages: `3598:8463`.
- Composer content types: `3598:8204` and `3598:8176`.
- Event cards, detail, comments: `3598:7971`, `3598:7774`, `3598:7805`.
- Primary blue `#0659FD`: `1:332`.

PNG photos/portraits and the original SVG assets in `public/assets` are exports from those supplied Figma nodes. Names and family roles are fictional demo data and do not identify the pictured people. The desktop navigation, parent review, personalized feeds, and calendar adapt the mobile references to this app’s requirements.

`flower.mp4` is the CC0 sample video from [MDN’s interactive examples](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4), stored locally for a self-contained video post.

Interface icons use [Phosphor Icons](https://phosphoricons.com/) via `@phosphor-icons/react` (MIT license), with regular outlines and filled active navigation icons.

Typography pairs General Sans Semibold (local Fontshare kit, license in public/fonts/GeneralSans-LICENSE.txt) for headings with Figtree via Google Fonts for body text and controls.
